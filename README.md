# Don't do that - Avoiding Python Anti-Patterns
This repository holds the code for my Python anti-patterns interactive presentation for PyCon Italia 2026


# How to view the presentation
## Molab
This presentation is available at the following [Link](https://molab.marimo.io/notebooks/nb_u8i4cJLx3bfH1v397XSnVB)
## Locally
- Clone the repo
- Install uv ```pip install uv```
- Install project dependencies ```uv sync```
- Run the notebook ```uv run marimo run dont_do_this.py```
